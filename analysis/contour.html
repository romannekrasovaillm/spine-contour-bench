Рука, последняя на одной модели, — первая на другой

Замер отвечает на вопрос «что внедрять»: формат вокруг документа, оболочку, которая его исполняет, или модель под ней. Ответы разные — и один из них не переносится.

CLI Spine ловит дефектов меньше Claude Code на модели dsf (−0.333) и больше на glm (+0.347 по восстановлению структуры). Значит «кто лучше» — это свойство связки «оболочка × модель», а не продукта.

формат → передача работы +1.000 полнота пакета передачи внутри Claude Code; +0.909 внутри Theseus, +0.800 внутри CLI Spine. У рук без формата пакета нет вовсе — 0.00.
формат → ловля дефектов +0.514 на модели dsf внутри Claude Code. На glm тот же эффект всего +0.167 и уже не значим: у модели без формата база выше (0.78 против 0.40).
харнесс → ловля дефектов −0.333 CLI Spine против Claude Code при одинаковом формате, модель dsf. Эта разница больше, чем вклад формата на другой модели.

Харнесс

Один формат, разные оболочки. На dsf CLI Spine последняя среди рук с контуром (0.62 против 0.92 и 0.92). На glm — первая (0.97 против 0.93 и 0.78).

Это смена порядка рук, а не сокращение отставания.

Модель

Рука без формата ловит 0.40 на dsf и 0.78 на glm. Голая модель без инструментов проходит гейт 0.67 против 0.17.

Эффект формата падает не потому, что формат хуже, а потому что закрывать стало нечего.

Что формат не улучшил

Две метрики остались на нуле, и это часть результата, а не умолчание: трассируемость «требование → решение» — разница +0.000, у рук без формата адресный след тоже есть; «гейт пройден целиком» — тоже +0.000, все руки его проходят, поэтому различает не бинарный признак, а доля зелёных правил (+0.064) и то, что поймано и что утекло.

Без чего числа читать нельзя

  • Оценка first-party. Spine — система автора бенчмарка, и в паре «CLI Spine против Claude Code» она проигрывает. Это довод в пользу непредвзятости замера, но раскрытие остаётся раскрытием.
  • Один прогон на 6 задачах и 2 повторах. Интервалы — bootstrap по парам; пары с базой 5–9 общих ячеек — ориентир, а не измерение.
  • Вклад формата в ловлю измерен только внутри Claude Code: стадия «преемник», по которой считаются поймано и утекло, шла на четырёх руках, и обе стороны пары «формат против без формата» есть только там. Для Theseus и CLI Spine это ещё не проверено.
  • У рук Claude glm-половина потеряна внешней квотой вендора, у Theseus часть ячеек не уложилась в единый бюджет времени. Обе потери названы, а не спрятаны.
  • Двенадцать дефектов измерения найдены и исправлены по ходу — включая те, что до правки выглядели как результат: скорер не видел версию стадии 1, вендор отвергал 96% запросов одной руки, вместо работы 23 раза подставлялся входной файл бенчмарка.
